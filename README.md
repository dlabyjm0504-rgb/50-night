# 50밤 — 브라우저 미니게임 포털

브라우저에서 바로 실행하는 한국어 미니게임 포털입니다. 로그인 화면에서 게임 메뉴로 이동한 뒤, 좀비 생존 게임 **50밤**을 비롯한 여러 아케이드 게임을 선택할 수 있습니다. 각 게임은 HTML Canvas로 그리며, HTML·CSS·JavaScript가 `index.html` 한 파일에 들어 있습니다.

## 게임 목록

현재 게임 선택 화면에 표시되는 게임은 6종입니다.

| 게임 | 종류와 목표 | 조작 |
| --- | --- | --- |
| **50밤** | 탑다운 좀비 생존 게임. 무기를 고르고 몰려오는 좀비를 상대합니다. 3개의 하트로 버티며, 60초마다 날짜가 바뀝니다. AI 시민이 따라오며 좀비를 공격하고, 설정 버튼으로 시민 AI를 끌 수 있습니다. | 방향키 이동, `S` 스케이트보드. 선택한 무기에 따라 `Space`로 공격하거나 물고기를 소환합니다. |
| **탕탕 특공대** | 탑다운 자동 공격 생존 게임. 좀비를 처치해 보석과 경험치를 모으고 무기를 강화하며 90초 동안 살아남습니다. | 방향키 이동. 공격은 자동으로 진행됩니다. |
| **veck.io** | 복셀풍 1인칭 슈팅 게임. 시점을 돌려 몰려오는 적을 찾아 처치합니다. | `WASD` 또는 방향키 이동, 마우스 이동으로 시점 조작, 마우스 클릭 또는 `Space` 발사. |
| **GEOMETRY DASH** | 장애물을 점프로 피하며 코스 끝까지 달리는 횡스크롤 액션 게임. | `Space`, `↑` 또는 클릭으로 점프. |
| **CAR RUSH** | 차량을 좌우로 조종해 장애물을 피하고 1,000m를 달리는 게임. | `←` / `→` 조종. |
| **SHOOTER** | 적을 피하면서 15명을 처치하는 탑다운 슈팅 게임. | 방향키 이동, `Space` 발사. |

다음 4종은 게임 화면 코드가 있지만 현재 선택 메뉴에서는 숨겨져 있습니다.

- **AMONG US 스타일 생존** — 임포스터를 피해 20초 동안 생존합니다.
- **BOSS RUSH** — 보스의 추격을 피하며 버팁니다.
- **BRAWL STARS 스타일 아레나 슈팅** — 적 8명을 처치합니다. 방향키로 이동하고 `Space`로 공격, `X`로 슈퍼 샷을 사용합니다.
- **PAPER.IO 스타일 영토 점령** — 자기 구역 밖으로 나가 영역을 그리고 안전하게 돌아와 땅을 넓힙니다.

## 실행 방법

1. 저장소를 내려받거나 복제합니다.
2. `index.html`을 최신 브라우저에서 엽니다.
3. 로그인 후 게임을 선택합니다.

빌드나 패키지 설치는 필요하지 않습니다. 웹 폰트는 Google Fonts에서 불러오므로 폰트 표시에는 인터넷 연결이 필요할 수 있습니다.

### 데모 로그인

- 아이디: `홍길동`
- 비밀번호: `1234`

이 로그인은 브라우저 안에서만 확인하는 데모용 화면입니다. 계정이나 데이터를 보호하는 실제 인증 기능은 아닙니다.

## 파일 구성

- `index.html` — 포털 화면, 스타일, 게임 로직
- `Image/` — 게임에서 사용하는 이미지 리소스
